# PrompTugal__Agent__ABP

Home of cl-6.abp@PrompTugal.dinis, the Agent Behaviour Policy agent of the cl-6 PrompTugal agents (dev branch only).

- `abp/policies.json`: the one policy file; `abp/<agent>.md`: generated, never edited by hand (`node abp/tools.mjs build`)
- `.claude/`: the hook (the kit's, unchanged: SHA-256 checked against https://sovereignwebsite.ai/abp/kit/) and its wiring
- `abp/runs/`, `abp/reports/`: run reports and the hourly review
- `site/factory/dinis-cruz/account-f/`: this agent's area; `site/keys/cl-6.abp.json`: its public key
